### <a name="architecture"></a> 2. Introduction & Architecture

**Introduction:** Smart City means using technology to improve quality of life. IoT is its backbone.

**Four-Layer Architecture:**
*   **Sensing Layer:** Sensors - LDR, DHT11, MQ135 for air quality, ultrasonic for parking
*   **Network Layer:** Data transfer via WiFi, LoRaWAN, 5G
*   **Data Processing Layer:** Cloud platforms like AWS, Blynk, data analytics
*   **Application Layer:** User apps - Smart traffic lights, waste management dashboard

### <a name="applications"></a> 3. Key Applications (with examples)

**1. Smart Traffic Management:** IoT sensors at signals count vehicles, AI adjusts green time. Case: Barcelona reduced traffic jams by 21%.

**2. Smart Waste Management:** Ultrasonic sensor in dustbin alerts when full. Route optimization saves fuel.

**3. Smart Energy & Street Lights:** LDR based lights

**4. Smart Water & Pollution Monitoring:** Water level sensor prevents overflow, MQ135 sensor sends AQI on mobile app.

**5. Smart Safety:** CCTV + IoT panic buttons.
